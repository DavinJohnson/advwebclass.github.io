Part C - $(document).ready() observations:

Temporarily removing $(document).ready() and leaving the script in the <head> broke the buttons: the click handlers ran before #hide1/#hide2 existed in the DOM, so $("#hide1") selected nothing and .click() attached to an empty jQuery object.

Script placement matters because the browser parses the page top to bottom. A script in the <head> (or anywhere before the elements it targets) runs before those elements exist, unless it waits - which is exactly what $(document).ready() does: it delays the code inside it until the full DOM has been parsed, so selectors reliably find the elements regardless of where the <script> tag sits on the page.
